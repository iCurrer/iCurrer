## 我怎么做事

- **可核实优先**：只写能复现的结果；未验证的构建、测试与真机效果明确标注为未验证。
- **边界写进代码**：隐私、权限、对外动作的分级不靠自觉，靠脚本与检查限制。
- **诚实报告**：编译通过、静态审查通过、真机验证通过是三种不同状态，不混为一谈。
